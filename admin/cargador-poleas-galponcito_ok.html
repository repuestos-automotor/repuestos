Cargador de Poleas (cuaderno + Bobinar)

Carga las 39 filas de la hoja POLEAS de los cuadernos (columna "Cant. PAPI" como cantidad) y las cruza con la lista de Bobinar (poleas_bobinar.xlsx, 539 líneas). Cada fila guarda el código real (el de tu planilla, editable) y el código Bobinar en códigos de proveedores, y precarga el costo con "Costo Final". El cruce lo propone el sistema (M0101 → DIPM101, etc.) pero tenés que revisarlo fila por fila: al lado de cada código ves el detalle de Bobinar, y si no coincide elegís otra línea del desplegable o escribís el código a mano. Nada se pisa: si el código ya existe en Firebase como polea, la fila queda bloqueada y te muestro cuál es. Las filas sin match con Bobinar quedan destildadas hasta que elijas código o cargues el costo.
