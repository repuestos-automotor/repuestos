Completar Bujes con datos Autolube / BYC

Cruza los bujes que ya cargaste (hoja BUJES de Galponcito) con dos catálogos: Equivalencia Autolube↔ByC (para el código alternativo) y el Catálogo BYC Bujes Automotor 2009/10 (que trae, para cada aplicación, el número de repuesto original del motor de arranque). Esta versión amplía la cobertura de aplicaciones respecto a la anterior. También suma dos acciones nuevas: fijar el precio de costo a todos, y aclarar la etiqueta de medidas (INT/EXT/LARGO) en las descripciones ya cargadas.
Buscando los bujes ya cargados en Firebase…

1) Precio de costo para todos los bujes

Fija el mismo costo a los — bujes cargados. El precio de venta se recalcula como costo × (1 + % ganancia), usando el % que ya tenga guardado cada repuesto (por defecto 40% si no tiene ninguno). Si tu forma de calcular el precio de venta es otra, avisame y lo cambio.

2) Aclarar medidas (INT / EXT / LARGO) en la descripción

Reemplaza, en la descripción de cada buje ya cargado, la etiqueta ambigua "Medida estándar (INT x EXT x LARGO)" por una aclarada:
INT = diámetro interior (por donde pasa el eje) · EXT = diámetro exterior (el que apoya contra la carcasa/alojamiento) · LARGO = longitud del buje. Todo en milímetros. No borra nada más de la descripción, solo aclara esa etiqueta puntual.

3) Aplicaciones y equivalencias (vehículos compatibles)

Por cada buje, cruza su código con las tablas de aplicación por marca/vehículo de ambos catálogos y agrega el código Autolube si falta.
